# Physiotherapist Website

## Overview

This website is designed for a physiotherapist, showcasing their services, expertise, and providing a modern, user-friendly experience. It is built using HTML, CSS, and JavaScript, incorporating modern design trends, GSAP (GreenSock Animation Platform) for smooth animations, and Lenis for enhanced scrolling.  The website is also SEO-optimized, responsive, and performance-optimized.

## Features

* **Modern Design:** The website features a contemporary design aesthetic, providing a professional and visually appealing experience.
* **GSAP Animations:** Smooth and engaging animations throughout the site, enhancing user interaction.
* **Lenis Scrolling:** Implements smooth scrolling, providing a polished and modern feel.
* **Responsive Layout:** The website is designed to be responsive, ensuring optimal viewing across various devices (desktops, tablets, and smartphones).
* **SEO Optimized:** The website is optimized for search engines to improve visibility and organic traffic.
* **Performance Optimized:** The website's code and assets are optimized for fast loading times and smooth performance.
* **Services Showcase:** Clearly presents the physiotherapist's range of services.
* **Expertise Highlight:** Showcases the physiotherapist's qualifications, experience, and areas of expertise.
* **Contact Information:** Provides easy access to contact details, enabling potential clients to get in touch.

## Technologies Used

* HTML: The standard markup language for creating web pages.
* CSS:  Used for styling the website and creating a visually appealing layout.
* JavaScript:  Used for interactive elements and dynamic content.
* GSAP (GreenSock Animation Platform): A powerful JavaScript library for creating high-performance animations.
* Lenis: A JavaScript library for creating smooth, modern scrolling effects.

## Installation

As this is a static website, there is no installation required. Simply download the files and open the `index.html` file in your web browser.
